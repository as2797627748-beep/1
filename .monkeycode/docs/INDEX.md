# 项目文档

## 项目概述

本项目是一个面向个人 VPS 自用场景的 AI 闭环写改测平台，目标是在 `1C1G` 资源约束下提供尽可能完整的模型接入、任务编排、代码执行、测试验证、暂停补需、部署修复和可视化操作能力。

## 设计目标

- 单机部署，优先低资源占用
- 支持多平台、多模型统一接入
- 提供可暂停、可补充需求、可恢复的工作流执行
- 提供内置模型目录、模板库、工具控制、执行去重和自动调度
- 支持应用级幂等重部署，不做系统级破坏性清理
- 前端交互风格参考 Trae，但不依赖重型桌面壳

## 技术选型

- 后端：Go
- 存储：SQLite
- 前端：React + Vite + TypeScript
- 通信：REST API + Server-Sent Events
- 部署：systemd + 单二进制服务 + 静态前端资源
